semicolon Privacy Policy

Last updated October 12, 2026

semicolon is a Discord bot run by one person as a hobby. It tries to store as little about you as it can. It doesn't sell your data, show ads, or use analytics or tracking. This page explains what it does store and why. Using semicolon also means agreeing to the Terms of Service.

What the bot stores

The bot tries to store only what is necessary for its functionality.

  • Starboard: if you are in a server with this feature enabled, the bot stores the fact that an amount of users have reacted to a certain message ID. This ID may correspond to a message you have created. It does not store who created the message, their name, or the contents of the message, only its unique identifier. If this message gets deleted, the bot too will delete what it knows of the message.
  • Reminders: if you ask the bot to remind you of something, it will store your user ID, the content of the reminder, when it should go off, your language, and where you set it (server, channel and message IDs). Public reminders are stored until they have elapsed to allow other users to join it. Private reminders are stored until they have elapsed or have been cancelled. If a reminder fails to get delivered, for example because you have DMs disabled, then for public reminders the bot will post it publicly in the channel you started it in, then delete the data. If it was a private reminder set within a server channel then the bot will attempt to contact you there to access the reminder once via a button exclusive to you. The reminder is deleted after you click the button or after a month. For private reminders initiated in DMs, the bot will continue attempting to contact you for a month before removing the reminder from the database.
  • Polls: if you use this command and the bot doesn't understand your input, it will store your input as a draft so you can quickly access and edit it. Drafts are deleted once the poll is posted, or after 24 hours.
  • Pokémon: if you use the catch command then your user ID, which Pokémon you've caught and when, and your display name are stored so they can be shown on the leaderboard.

The rest of the bot's functionality is stored per-server and managed by its moderators.

  • Channels: the bot stores the IDs of what channels it should post member logs in. Database entries are cleared when the corresponding channels are deleted.
  • Rules: the bot stores what rules should be offered to members trying to report a message.
  • Roles: the bot stores the IDs of what roles you want members to be able to self-assign and a description for them. Database entries are cleared when the corresponding roles are deleted.
  • Subscriptions: the bot stores what RSS feeds to check for new items and the IDs of what channels to post them in. Database entries are cleared when the corresponding channels are deleted.
  • Antispam: on top of channel storage, the bot stores how many repetitive messages should trigger an automatic mute.
  • Starboards: the bot stores the configuration including channel ID, emoji, and threshold. It also stores previously configured emojis and thresholds, as well as all message IDs that have hit the threshold and been posted in the channel by the bot. Database entries are cleared when the corresponding message(s) or channel(s) are deleted.

What the bot doesn't store

To run its moderation features, semicolon can read messages and the member list in servers it's in. Antispam remembers recent messages for about 20 seconds to spot repeats. To provide server administrators logs, the bot stores recent messages and members in memory so it can show what changed when something is edited or deleted. These are sent to the server moderators who may retain the logs.

When something breaks, the bot writes an error log that may include Discord IDs, server names, and stacktraces. These are used to fix bugs and removed afterwards.

Features server administrators control

Server administrators can turn on features that post information about members into their own server's channels:

  • Logs of joins, leaves, bans, timeouts, role changes and username changes
  • Logs of edited and deleted messages, including what they said
  • Reports, which include the reported message
  • Antispam alerts, which include the flagged messages
  • Starboard posts, which repost the starred message

These messages are stored by Discord in that server, not by semicolon. The bot doesn't keep its own copy. That server's administrators decide who can see them and how long they're kept. If you have questions about them, ask the server's administrators.

Other services

  • Discord: semicolon runs on Discord, so Discord's Privacy Policy applies too.
  • PluralKit: the bot sends message IDs to PluralKit to check whether a message was reposted by PluralKit. This helps it cleanup antispam alerts and avoids false deletion logs.

The bot also downloads data from PokéAPI, YouTube, and xkcd, but it doesn't send them anything about you.

Deleting your data

Send a DM to qixils on Discord and I'll delete everything semicolon has stored about you. If you provide your server ID then I'll verify through the bot that you have moderator permissions within that server and delete everything semicolon has stored about it.

Deleting your data doesn't remove messages the bot has already posted in servers, such as logs or starboard posts. Ask that server's administrators about those.
